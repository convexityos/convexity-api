# API changelog

Notable changes to the public `/api/v1` surface. The OpenAPI snapshot in this repo is refreshed alongside each entry, so the commit history of `openapi.json` is the machine-readable diff log.

## 2026-07-11

- Initial public snapshot: 22 routes (quotes, price history, reference, related companies, events, screener, Convexity Score, webhooks, exports, limits).
- MCP server manifest and connection guide (12 tools, Streamable HTTP).
- Quickstart examples: curl, Python, TypeScript.
